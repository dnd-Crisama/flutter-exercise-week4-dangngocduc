# Bài Tập Flutter Tuần 4
Các bài tập học tập về những khái niệm cơ bản của Flutter bao gồm ListView, GridView, SharedPreferences, lập trình không đồng bộ (Async).

## Hướng Dẫn Cài Đặt

### Requirements

- **Flutter SDK:** Phiên bản 3.0 trở lên
- **Dart SDK:** Tự động đi kèm với Flutter
- **IDE:** Android Studio, VS Code

### Bước 1: Clone Dự Án

```bash
git clone https://github.com/dnd-Crisama/flutter-exercise-week4-dangngocduc.git
cd flutter_exercise_week4
```

### Bước 2: Lấy Các Gói Phụ Thuộc

```bash
flutter pub get
```

### Bước 3: Chạy Ứng Dụng

```bash
flutter run
```
